# Windows-Endpoint-Audit
Created a PowerShell script to perform an audit of Windows Endpoint devices.

I have created a PowerShell script that extracts information as per my Windows endpoint checklist and generates an HTML output 

To run this script, rename the text file as ps1
Run PowerShell with admin rights.  

Enter this command: Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force ...temporarily allow script execution
  
Run the script: filepath\script.ps1  ...an HTML file will be generated at the script  path.
